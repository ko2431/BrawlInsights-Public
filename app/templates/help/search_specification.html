{% if lang == "ja" %}高度な検索{% else %}Advanced Search{% endif %}

{% if lang == "ja" %} プレイヤー検索とクラブ検索では、「_」と「%」を使うことで、より高度な検索を行うことができます。
「_」は任意の1文字以上、「%」は任意の0文字以上にマッチします。
たとえば、「Brawl%Stars」は、「Brawl Stars」にも「brawlstars」にもマッチします。「Brawl_Stars」は「brawlstars」にはマッチしません。
なお、完全一致する名前のみ検索をオンにしていると、「_」と「%」は実際の「_」および「%」として解釈されます。 {% else %} In player and club searches, you can use "_" and "%" to perform more advanced searches.
"_" matches one or more arbitrary characters, while "%" matches zero or more arbitrary characters.
For example, "Brawl%Stars" will match both "Brawl Stars" and "brawlstars". However, "Brawl_Stars" will not match "brawlstars".
Note: if search only exact name matches is enabled, "_" and "%" will be interpreted as literal "_" and "%" characters. {% endif %}

{% if lang == "ja" %}その他の仕様{% else %}Other Specifications{% endif %}

{% if lang == "ja" %} ・検索結果の画面で、「？」のプレイヤーアイコン、または初期クラブアイコンが表示されていたり、トロフィーの値が「不明」となっていたりすることがあります。これは負荷軽減のための措置です。プレイヤーの閲覧後は正しいアイコンとトロフィーの値が反映されます。
・改名前の名前を含めて検索で検索対象となる改名前の名前は、各プレイヤープロフィールページで閲覧できる改名履歴の範囲と同じです。 {% else %} ・In the search results screen, you may see a "?" player icon, an initial/default club icon, or a trophy count listed as "Unknown". This is an intentional measure to reduce server load. After viewing the player’s details, the correct icons and trophy count will be updated.
・The names included when include previous names is enabled are limited to those shown in the name history on each player's profile page. {% endif %}
