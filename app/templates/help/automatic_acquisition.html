{% if lang == "ja" %}プレイヤー自動追跡機能とは{% else %}About the player auto-tracking feature{% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能は、本サービスが従来(=プレイヤー自動追跡機能が無効のプレイヤー)よりも高い頻度で該当プレイヤーのデータをバックグラウンド取得・更新することにより、本サービス上で閲覧できる改名履歴、クラブ履歴、バトル履歴、推移グラフなどのデータの欠損を大幅に生じさせにくくする機能です。
特にバトル履歴に関しては、この機能の有効/無効によって欠損のしにくさが大幅に変わります。ただし、機能が有効になっていても、1試合が短い低トロフィー帯のマルチの連続プレイをした場合などでは、欠損が生じることがあります。欠損を確実に生じさせないようにするには、25戦プレイするごとにページにアクセスまたは再読み込みしてください。
この機能の有効/無効にかかわらず、定期的にプレイヤーのページに実際にアクセスすれば、そのプレイヤーのデータの欠損は生じません。具体的には、改名履歴、クラブ履歴、推移グラフについては毎日、バトル履歴については25戦プレイするごとにアクセスすれば、データの欠損は生じません。
また、この機能とは関係なく、本サービス上で閲覧できる各種データは、初めてBrawl Insightsで該当プレイヤーが閲覧された日からのデータとなります。 {% else %} The player auto-tracking feature enables Brawl Insights to automatically fetch and update the corresponding player's data more frequently than usual (i.e., for players without auto-tracking enabled), significantly reducing the risk of missing data such as name change logs, club logs, battle logs, and progression graphs.
In particular, battle logs are highly affected by whether this feature is enabled or not. With auto-tracking, the likelihood of missing data is greatly reduced.
Regardless of whether auto-tracking is enabled, data loss can be prevented simply by visiting the player's page regularly. Specifically, visiting the page once a day prevents missing data for name change logs, club logs, and progression graphs, and visiting after every 25 battles prevents missing battle logs.
Note that all data available on Brawl Insights is only recorded from the day the corresponding player was first viewed on this service, regardless of whether the auto-tracking feature is used. {% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能を有効化する方法{% else %}How to enable the player auto-tracking feature{% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能を有効化する方法は2つあります。
1. プレイヤーのページにアクセスして自動で有効化
2. 10トークンまたは24エリクサー消費して24時間、または90トークンまたは216エリクサー消費して10日間有効化 (残り時間が365日間に達するまで重ねがけ可。十分なエリクサーを所持している場合はトークンの代わりにエリクサーが消費されます。トークン・エリクサーに関する詳細はアカウントタブをご覧ください)
このうち、1番については一定のレベル以上のプレイヤーに限ります。一定のレベル以上のプレイヤーは、ページにアクセスされるたびに自動有効化時間まで有効時間が延長されます(負荷軽減のため、一度延長処理が行われると30分間は再度行われません)。
この自動有効化時間はプレイヤーのレベルが高いほど長くなります。具体的には下表のとおりです。
表にある4つの項目について、それぞれ対応する自動有効化時間を計算したあと、その4つのうち最も長いものが適用されます。 {% else %} There are two ways to enable the player auto-tracking feature:
1. Visit the player’s page to enable it automatically
2. Consumes 10 tokens or 24 elixir to activate for 24 hours, or 90 tokens or 216 elixir to activate for 10 days (Can be stacked until the remaining time reaches 365 days. If you have enough elixir, it is used instead of tokens. For more information about tokens and elixir, please refer to the Account tab.)
The first method is only available for players above a certain level. When such players' pages are accessed, their tracking duration is automatically extended up to the auto-enable time. (To reduce server load, this extension can only occur once every 30 minutes.)
The higher the player's level, the longer their auto-enable time. Details are shown in the table below.
Auto-enable time is calculated separately for four criteria, and the longest among the four is applied. {% endif %}

{% if lang == "ja" %}ガチバトルポイント変動表示 (ベータ版){% else %}Ranked Score Changes (Beta){% endif %}

{% if lang == "ja" %}バトル履歴ページのガチバトルタブでは、各バトルセットのポイント変動が表示されます。ただし、この機能は負荷が高いため、プレイヤー自動追跡機能とは関係ない独自の表示条件を設けています。
ポイント変動を表示するには、各バトルセットの始まる前と後にそれぞれ、実際にプレイヤーのページにアクセスする必要があります。つまり、ガチバトルを回している間、セットが終わるたびにページにアクセス(または再読み込み)すれば、その間のすべてのセットのポイント変動が表示されます。
なお、この機能はロジックが複雑なため、まれに条件を満たしていてもポイント変動が表示されなかったり、2セットぶんのポイント変動がまとめて表示されてしまったりすることがあります。ご了承ください。
ガチバトルを回している間、iPadでプレイしている場合はiPadのSlide Over機能(マルチタスク機能)で、スマートフォンでプレイしている場合は別途PC等でガチバトル履歴ページを表示しておき、セットが終わるたびにページをリロードする使い方がおすすめです。そうすれば、すべてのセットのポイント変動が表示され、ポイント変動を振り返りながらガチバトルを回すことができます！
※ガチバトル履歴ページの上の方にあるポイント推移グラフについては、取得できなかった部分のガチバトルスコアはスキップされ、自然に点が繋がれてグラフが描画されます。こちらもご利用ください！ {% else %} The ranked tab on the battle log page shows the score variation for each battle set. However, due to the high load of this feature, it has its own display requirements that are not related to the player auto-tracking feature.
In order to view score fluctuations, the player's page must actually be accessed before and after each battle set begins, respectively. In other words, while playing ranked, if you access (or reload) the page after each set, you will see the score variation for all sets during that time.
Please note that due to a glitch or some other reason, score changes may not be displayed even if the conditions are met, or in rare cases, score changes for two sets may be displayed at once. Please be aware of this. {% endif %}
