{% if lang == "ja" %}プレイヤー自動追跡機能とは{% else %}About the player auto-tracking feature{% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能は、本サービスが従来(=プレイヤー自動追跡機能が無効のプレイヤー)よりも高い頻度で該当プレイヤーのデータをバックグラウンド取得・更新することにより、本サービス上で閲覧できる改名履歴、クラブ履歴、バトル履歴、推移グラフなどのデータの欠損を大幅に生じさせにくくする機能です。
特にバトル履歴に関しては、この機能の有効/無効によって欠損のしにくさが大幅に変わります。ただし、機能が有効になっていても、1試合が短い低トロフィー帯のマルチの連続プレイをした場合などでは、欠損が生じることがあります。欠損を確実に生じさせないようにするには、25戦プレイするごとにページにアクセスまたは再読み込みしてください。
この機能の有効/無効にかかわらず、定期的にプレイヤーのページに実際にアクセスすれば、そのプレイヤーのデータの欠損は生じません。具体的には、改名履歴、クラブ履歴、推移グラフについては毎日、バトル履歴については25戦プレイするごとにアクセスすれば、データの欠損は生じません。
また、この機能とは関係なく、本サービス上で閲覧できる各種データは、初めてBrawl Insightsで該当プレイヤーが閲覧された日からのデータとなります。 {% else %} The player auto-tracking feature enables Brawl Insights to automatically fetch and update the corresponding player's data more frequently than usual (i.e., for players without auto-tracking enabled), significantly reducing the risk of missing data such as name change logs, club logs, battle logs, and progression graphs.
In particular, battle logs are highly affected by whether this feature is enabled or not. With auto-tracking, the likelihood of missing data is greatly reduced.
Regardless of whether auto-tracking is enabled, data loss can be prevented simply by visiting the player's page regularly. Specifically, visiting the page once a day prevents missing data for name change logs, club logs, and progression graphs, and visiting after every 25 battles prevents missing battle logs.
Note that all data available on Brawl Insights is only recorded from the day the corresponding player was first viewed on this service, regardless of whether the auto-tracking feature is used. {% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能を有効化する方法{% else %}How to enable the player auto-tracking feature{% endif %}

{% if lang == "ja" %}プレイヤー自動追跡機能は、次の2つの方法で有効になります。
1. プレイヤーのページが開かれると、自動で有効化（一定のレベル以上のプレイヤーのみ）
2. プレイヤーのページの「延長する」から、トークンまたはエリクサーを使って延長（アプリ版では、広告の視聴で1日ずつ無料で延長することもできます。1日5回まで）
2番の料金は下表のとおりです。カスタムでは日数を1日単位で指定でき、10日ごとに10日間の料金、端数の日は1日の料金で計算されます（例: 23日間なら 90×2＋10×3＝210トークン）。残り時間が365日に達するまで重ねて延長できます。トークン・エリクサーについて詳しくはアカウントタブをご覧ください。 {% else %} The player auto-tracking feature can be enabled in two ways:
1. Automatically, when the player's page is opened (only for players above a certain level)
2. From "Extend" on the player's page, using tokens or elixir (in the app, you can also extend by 1 day for free by watching an ad, up to 5 times a day)
Prices for method 2 are shown below. With Custom, you can choose any number of days; every 10 days are charged at the 10-day price and the remaining days at the 1-day price (e.g. 23 days = 90×2 + 10×3 = 210 tokens). You can keep extending until the remaining time reaches 365 days. For more about tokens and elixir, see the Account tab. {% endif %}

Each time such a player's page is opened, the remaining time is topped up to the auto-enable time (to reduce server load, this happens at most once every 30 minutes).

On the player's page, the gauge has evenly spaced marks so that short remaining times are still visible, which means each mark covers more time toward the right. {% if lang == "ja" %}バトル履歴の保存期間{% else %}Battle log storage period{% endif %}

{% if lang == "ja" %}負荷軽減のため、バトル履歴は保存期間を過ぎると順次削除され、その期間のバトル履歴やグラフなども見られなくなります。
保存期間は最初は{{ settings.DEFAULT_BATTLE_LOG_RETENTION_MONTHS }}ヶ月で、プレイヤーのページの「延長する」から、1ヶ月あたり100トークンまたは240エリクサーで延長できます（最大10年）。何ヶ月延長するかは、カスタムで1ヶ月単位で指定できます。昔のシーズンのバトル履歴やグラフも振り返りたい場合は、早めの延長がおすすめです。 {% else %} To reduce server load, battle logs older than the storage period are removed over time, and battle logs and graphs for that period can no longer be viewed.
The storage period starts at {{ settings.DEFAULT_BATTLE_LOG_RETENTION_MONTHS }} month{{ 's' if settings.DEFAULT_BATTLE_LOG_RETENTION_MONTHS > 1 else '' }} and can be extended from "Extend" on the player's page for 100 tokens or 240 elixir per month (up to 10 years). With Custom, you can choose how many months to add. If you want to look back at battle logs and graphs from past seasons, we recommend extending early. {% endif %}

{% if lang == "ja" %}ガチバトルポイント変動表示 (ベータ版){% else %}Ranked Point Changes (Beta){% endif %}

{% if lang == "ja" %}バトル履歴ページのガチバトルタブでは、各バトルセットのポイント変動が表示されます。ただし、この機能は負荷が高いため、プレイヤー自動追跡機能とは関係ない独自の表示条件を設けています。
ポイント変動を表示するには、各バトルセットの始まる前と後にそれぞれ、実際にプレイヤーのページにアクセスする必要があります。つまり、ガチバトルを回している間、セットが終わるたびにページにアクセス(または再読み込み)すれば、その間のすべてのセットのポイント変動が表示されます。
なお、この機能はロジックが複雑なため、まれに条件を満たしていてもポイント変動が表示されなかったり、2セットぶんのポイント変動がまとめて表示されてしまったりすることがあります。ご了承ください。
ガチバトルを回している間、iPadでプレイしている場合はiPadのSlide Over機能(マルチタスク機能)で、スマートフォンでプレイしている場合は別途PC等でガチバトル履歴ページを表示しておき、セットが終わるたびにページをリロードする使い方がおすすめです。そうすれば、すべてのセットのポイント変動が表示され、ポイント変動を振り返りながらガチバトルを回すことができます！
※ガチバトル履歴ページの上の方にあるポイント推移グラフについては、取得できなかった部分のガチバトルポイントはスキップされ、自然に点が繋がれてグラフが描画されます。こちらもご利用ください！ {% else %} The ranked tab on the battle log page shows the point change for each battle set. However, due to the high load of this feature, it has its own display requirements that are not related to the player auto-tracking feature.
In order to view point changes, the player's page must actually be accessed before and after each battle set begins, respectively. In other words, while playing ranked, if you access (or reload) the page after each set, you will see the point change for all sets during that time.
Please note that due to a glitch or some other reason, point changes may not be displayed even if the conditions are met, or in rare cases, point changes for two sets may be displayed at once. Please be aware of this. {% endif %}
