Brawl Insights is {% if platform == "web" %}a web-based platform{% else %}the app{% endif %} for analyzing Brawl Stars player data.
It offers powerful features such as player search by name, viewing name and club history, checking battle logs by type (Trophies / Ranked / Friendly), battle breakdowns by brawler, and visualizing player progress with timeline graphs.

{% if lang == "ja" %}基本的な使い方ガイド{% else %}Usage Guide{% endif %}

{% if lang == "ja" %}

推定プレイ時間、改名・クラブ履歴、装備スキンなどのプレイヤーに関する情報は、各プレイヤーページより確認できます。このページの上の方に移動して、プレイヤータグまたはプレイヤー名で検索して、プレイヤーページに移動することができます。

一緒にプレイした人のグラフ、ガチバトルのポイント推移・勝率・キャラ使用率などのグラフは、プレイヤーページに移動しバトル履歴タブを選択すると確認できます。

プレイヤー名で検索では、一度もBrawl Insightsで閲覧されたことのないプレイヤーは検索できないことがあります。プレイヤータグで検索では、ブロスタがメンテナンス中でない限り、必ず全てのプレイヤーを検索できます。プレイヤータグでの検索ができない場合は、入力間違いがないか確認をお願いします。

ログインすることで、ブックマークや閲覧履歴表示、募集掲示板の追加機能などが利用できるようになり、さらに便利にご利用いただけます。なお、アカウント作成にメールアドレス等は不要です。任意のユーザー名とパスワードを入力すればすぐに作成できます。

ガチバトルTier表やスキン使用率ランキング、その他各種ランキングは統計データタブから、プロフィール画像生成ツール、ガチバトルピック提案ツール、マップ周期、キャラクターステータス／スキン図鑑、育成計算機やトロフィー増減表などの各種ツールはツールタブからご利用いただけます。

掲示板タブでは、条件指定機能とチャット機能を備えた高度な各種掲示板をご利用いただけます。チーム募集、フレンド募集、クラブ募集、なんでも掲示板、テーマ掲示板の5種類の掲示板があります。

よくある質問もぜひご確認ください！

Information about players, such as estimated play time, name change / club log, and equipped skins, can be found on each player's page. You can go to the top of this page and search by player tag or player name to navigate to a player page.

Graphs such as players you played with, and ranked score trend, win rates, and brawler usage rates can be viewed by going to the player page and selecting the battle log tab.

When searching by player name, you may not be able to find players who have never been viewed on Brawl Insights. When searching by player tag, you can always find all players as long as Brawl Stars is not under maintenance. If you cannot search by player tag, please check for any input errors.

By logging in, you can use additional features such as bookmarks, viewing history, and advanced features for the recruitment boards, making it even more convenient. No email address is required to create an account. You can create one immediately by entering your desired username and password.

Ranked Brawler Tier List, Skin Usage Ranking, and various leaderboards are available from the stats tab, and various tools such as the profile image generator, ranked pick suggestion tool, map rotation, brawler stats guide, level-up cost calculator and trophy change table are available from the tools tab.

The Boards tab offers advanced boards with condition filters and chat. There are five types: Team Recruitment, Friend Recruitment, Club Recruitment, General Board, and Theme Board.

App FAQ is also available.
