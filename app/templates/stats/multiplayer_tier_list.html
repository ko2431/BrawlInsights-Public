{% if lang == "ja" %}集計方法についての詳細{% else %}Details on Data Aggregation{% endif %}

{% if lang == "ja" %}

勝敗データの集計期間は過去30日間です。できる限り実態にそったTier表になるよう、バトルの新しさやトロフィー帯によって重みを変えて集計しています。
モードごとに勝率・使用率・MVP率の比重を変え、異なるモードでも比較しやすいスコアになるようにしています。
キャラクターの試合数が少なく、信頼性のある総合スコアが算出できない場合は、総合スコアは0となります。


ページ上のメニューより並び替えを使用率順にすることで、各キャラクターの使用率を見ることができます。ただし、この値は実態に合わせるために重み付けをした後の値のため、合計は100%にはなりません。
データは毎日19時ごろに、自動で更新されます。

{% else %}

The match data is aggregated from the last 30 days. To create a tier list that reflects the current meta as accurately as possible, we apply a weighting system based on the recency of the battle and trophy range.
Each mode changes the weighting of win rate, use rate, and star player rate, making it easier to compare brawlers across different modes.
If a brawler has too few games for a reliable score, their score will be 0.


You can view the use rate for each brawler by sorting by Use Rate from the menu at the top of the page. However, please note that this value is a weighted figure to better reflect the meta, so the total will not add up to 100%.
The data is automatically updated daily around 10:00 AM (UTC).
