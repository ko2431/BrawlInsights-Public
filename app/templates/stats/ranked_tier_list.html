{% if lang == "ja" %}集計方法についての詳細{% else %}Details on Data Aggregation{% endif %}

{% if lang == "ja" %}

勝敗データの集計期間は過去30日間で、すべてのランク帯が集計対象です。ただし、できる限り実態にそったTier表になるよう、バトルの新しさやランク帯によって、最大で1000倍以上重みを変えて集計しています。
Tier表は、重み付けされた使用率・勝率・MVP率・推定BAN率などから算出した総合スコアでランク付けしています。ただし、キャラクターの使用率が極端に低く、信頼性のある総合スコアが算出できない場合は、総合スコアは0となります。


ページ上のメニューより並び替えを使用率順にすることで、各キャラクターの使用率を見ることができます。ただし、この値は実態に合わせるために重み付けと調整をした後の値のため、合計は100%にはなりません。
データは毎日16-17時ごろに、自動で更新されます。

{% else %}

The match data is aggregated from the last 30 days and includes all rank tiers. However, to create a tier list that reflects the current meta as accurately as possible, we apply a weighting system that can vary by more than 1000 times based on the recency of the battle and the rank tier.
The tier list is ranked by a strength score calculated from weighted metrics such as use rate, win rate, star player rate, and estimated ban rate. However, if a brawler's use rate is extremely low and a reliable strength score cannot be calculated, their score will be 0.


You can view the use rate for each brawler by sorting by Use Rate from the menu at the top of the page. However, please note that this value is a weighted figure to better reflect the meta, so the total will not add up to 100%.
The data is automatically updated daily around 7-8 AM (UTC).
